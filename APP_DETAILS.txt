App Name: Gramin Saathi (ग्रामीण साथी)
Tagline: Digital Financial Companion for Rural India
Version: 1.0.0
Platform: Progressive Web App (PWA)
Languages: Hindi (हिंदी), English

================================================================================
                                  OVERVIEW
================================================================================

Gramin Saathi is a mobile-first, offline-first Progressive Web App designed to 
empower rural farmers and communities in India with digital financial tools, 
government scheme access, market price information, and AI-powered assistance.

The app works in low-connectivity areas and can be installed on any device 
(Android, iOS, Windows, macOS) as a standalone application.

================================================================================
                              TECHNOLOGY STACK
================================================================================

FRONTEND:
- React 18.3.1 (UI Framework)
- TypeScript (Type-safe JavaScript)
- Vite 5.x (Build tool and dev server)
- Tailwind CSS 3.x (Utility-first CSS)
- Lucide React (Icon library - 300+ icons)
- Recharts (Data visualization/charts)
- date-fns (Date utilities)

BACKEND & DATABASE:
- Firebase Authentication (Email/Password, Google OAuth)
- Cloud Firestore (NoSQL database)
- Firebase Analytics

OFFLINE & PWA:
- vite-plugin-pwa (Service worker generation)
- Workbox (Caching strategies)
- Dexie.js 4.x (IndexedDB wrapper)
- workbox-window (Service worker registration)

EXTERNAL APIS:
- data.gov.in API (Mandi/APMC market prices)
- OpenWeatherMap API (Weather forecasts)
- Google Gemini AI API (Saathi assistant)

VOICE & SPEECH:
- Web Speech API (SpeechRecognition - voice input)
- Web Speech API (SpeechSynthesis - text to speech)

================================================================================
                           OFFLINE ARCHITECTURE
================================================================================

SERVICE WORKER CACHING:

| Content Type       | Strategy       | TTL          |
|--------------------|----------------|--------------|
| Static Assets      | Cache-First    | Indefinite   |
| Google Fonts       | Cache-First    | 1 year       |
| Mandi API          | Network-First  | 1 hour       |
| Weather API        | Network-First  | 30 minutes   |
| Images             | Cache-First    | 30 days      |

INDEXEDDB TABLES (Dexie.js):

1. mandiPrices
   - id (auto-increment)
   - commodity, market, district, state
   - modal_price, min_price, max_price
   - arrival_date, timestamp

2. weather
   - id (auto-increment)
   - location
   - data (JSON)
   - timestamp

3. lessonProgress
   - lessonId (primary key)
   - progress (0-100)
   - completed (boolean)
   - score
   - lastAccessed

4. transactions
   - id (auto-increment)
   - firestoreId
   - type (income/expense)
   - amount
   - description
   - category
   - date
   - synced (boolean)
   - createdAt

5. preferences
   - key (primary key)
   - value (any)

6. syncQueue
   - id (auto-increment)
   - action (create/update/delete)
   - collection
   - documentId
   - data
   - createdAt
   - retries

SYNC MANAGER:
- Queues offline changes
- Auto-syncs when online detected
- 5-minute sync interval when online
- Retry logic (max 3 attempts)
- Status updates via React hooks

================================================================================
                           API INTEGRATIONS
================================================================================

1. DATA.GOV.IN (MANDI PRICES)
   URL: https://api.data.gov.in/resource/9ef84268-d588-465a-a308-a864a43d0070
   Method: GET
   Parameters:
   - api-key: (required)
   - format: json
   - limit: 1-500
   - offset: pagination
   - filters[state]: filter by state
   - filters[commodity]: filter by commodity
   - filters[district]: filter by district
   - filters[market]: filter by market
   Response Fields:
   - commodity, market, district, state
   - modal_price, min_price, max_price
   - arrival_date

2. OPENWEATHERMAP
   URL: https://api.openweathermap.org/data/2.5/
   Endpoints:
   - /weather (current weather)
   - /forecast (5-day forecast)
   Parameters:
   - appid: API key
   - q: city name
   - lat, lon: coordinates
   - units: metric

3. GOOGLE GEMINI AI
   Model: gemini-pro
   Usage: Chat completions
   Features:
   - System prompt for rural India context
   - Conversation history
   - Hindi/English responses
   - Fallback for API errors
